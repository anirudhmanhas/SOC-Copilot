The Solution (What It Delivers)

The 4 Core Defense Pillars

1. Multi-Source Ingestion & Active Drop

Standardizes perimeter firewalls (KV), Nginx web logs, and Linux SSH logs. Traffic from blocked adversary IPs is actively dropped at perimeter ingestion.

2. MITRE Kill-Chain Correlation

Sliding 10-minute temporal windows and IP/user pivot clustering collapse dozens of atomic alerts into ONE unified incident campaign, escalating severity as the attack progresses.

3. Google Gemini 3.5 Flash RAG Triage

Retrieval-Augmented Generation feeds incident timelines and curated MITRE technique definitions into Gemini 3.5 Flash for natural-language executive summaries and confidence scores.

4. Safe Human-in-the-Loop Containment

AI only recommends; execution strictly requires operator confirmation. 1-click firewall IP drops, user disablement, and ticketing with full audit compliance logging.

How It Works (Architecture)

The 6-Stage Autonomous Pipeline

Stage 01
Resilient Ingestion

Regex-powered parsers extract ECS fields and enforce active firewall drop filters.

Stage 02
Rule Evaluation

11 YAML rules match threshold, distinct port, and regex signatures with deduplication.

Stage 03
MITRE Correlation

Aggregates atomic hits into incidents based on 10-minute sliding windows and pivots.

Stage 04
Gemini RAG Triage

Injects MITRE definitions and outputs strict JSON executive triage summaries.

Stage 05
1-Click Containment

Enforces analyst verification modal and logs immutable audit records.

Stage 06
Real-Time WebSockets

Broadcasts live alert toasts, map coordinates, and incident state changes instantly.
